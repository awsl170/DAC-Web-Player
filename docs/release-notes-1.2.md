# DAC Web Player 1.2

本版以「用起来顺手」为主：服务器文件页能搜索和整目录播放，电视上的焦点高亮可以按屏幕方向开关，插上 DAC 播在线曲目时进度条与声音对齐。播放核心、插件、网络协议栈的行为与 1.1 一致。

## 新功能

- **服务器文件页搜索**：SMB / FTP / SFTP / WebDAV 的文件浏览页新增搜索条，回车后从当前目录往下递归查找音频文件（单次最多 800 首，显示扫描进度），结果列表可以点播。
- **播放整个文件夹**：文件浏览页新增「播放此文件夹」按钮，递归收集当前目录及其子目录下的音频，按路径排序后整队列播放（搜索状态下播放的是搜索结果）。
- **遥控器焦点效果可开关**：设置 → 主题新增「遥控器焦点效果」，可选 自动 / 总是开启 / 总是关闭。自动模式只在「横屏且最小宽度 ≥ 600dp」（电视、投影等大屏）时显示焦点描边，竖屏手机默认不显示。

## 修复

- **插 DAC 播在线曲目时进度条先跑、声音后到**：换曲时先让 DAC 以静音方式预热缓冲，ExoPlayer 同步暂停等待，缓冲到 2/3（或 4 秒超时）后两边一起开始，歌词与进度不再超前。
- **在线曲目被降采样**：网络源首次解析失败时，采样率探测会重试 3 次，避免直接把 96 kHz 曲目按 48 kHz 开流后重采样。
- **Android 5.x 桌面图标空白**：启动图标原来是 `layer-list` 内嵌 vector，5.x 桌面加载会失败。现改为各密度 PNG（紫色底 + 白色双音符），Android 8+ 仍用自适应图标。
- **DAC 页把板载蓝牙/Wi-Fi 模块当成 DAC 列出**：如电视内部 MediaTek `0E8D:76A1`「BT+WIFI」组合模块也挂在 USB 总线上。现在只把带音频接口（UAC）的设备显示为卡片，其余设备用一行说明带过。

## 安装

- 支持 Android 5.1（API 22）及以上，含电视/盒子。
- 三个 ABI：`arm64-v8a` / `armeabi-v7a` / `x86_64`。
- 与 1.1 同一 `applicationId`（`com.dacweb.player`）与签名，已装 1.1 / 1.1.1 的设备可直接覆盖升级。

## 已知限制

- 与 1.1 相同：SFTP / WebDAV 后端尚未做过服务端实测（代码与 FTP 同结构，建议首次连接时先用小目录验证）。
- USB DAC 独占直通仍只处理本地文件与直链，网络文件（`dacnet-*`）在插入 DAC 时回落到普通播放路径。
- 逐字（卡拉 OK 式）歌词未实现，仍是整行时间轴。
- 预热缓冲期间通知栏会短暂显示暂停状态。

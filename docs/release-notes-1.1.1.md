# DAC Web Player 1.1.1

本版是 1.1 的维护版：不新增功能，主要解决「退出应用后音频缓存长期占空间」这一个用户可感知的问题，其余是体积与仓库整洁方面的内部整理。播放、插件、USB DAC 直通、网络文件服务器的行为与 1.1 一致。

## 修复

- **退出应用后音频缓存不释放**：1.1 起网络与本地播放都会往 `cacheDir/audio_cache` 写 media3 缓存（上限 1.5 GB），退出后仍然留在设备上。现在播放服务结束时（`onDestroy`）调用 `MediaCache.purge()` 清空该目录，不再长期占用几十到几百 MB。
- **「关于」页的更新日志过长**：原来的整页更新日志挪到独立子页面（`ChangelogActivity`），关于页只保留入口，内容也做了精简，只保留每个版本的要点。

## 改进

- **APK 体积**：FFmpeg 头文件从 402 个去重合并为 134 个（仅影响构建输入，运行时行为不变）；debug 包约 19.1 MB、release 包约 15.5 MB。

## 安装

- 支持 Android 5.1（API 22）及以上，含电视/盒子。
- 三个 ABI：`arm64-v8a` / `armeabi-v7a` / `x86_64`。
- 签名证书 SHA-256：`0d468bb5e29f341b5d1f89ccf60edf0b43a970bbfd8d1c928d039c9422f28689`（与 1.0 / 1.1 相同，可直接覆盖安装，无需卸载）。
- 与 1.1 同一 `applicationId`（`com.dacweb.player`）与签名，已装 1.1 的设备可直接升级。

## 已知限制

- 与 1.1 相同：SFTP / WebDAV 后端尚未做过服务端实测（代码与 FTP 同结构，建议首次连接时先用小目录验证）。
- USB DAC 独占直通仍只处理本地文件与直链，网络文件（`dacnet-*`）在插入 DAC 时回落到普通播放路径。
- 逐字（卡拉 OK 式）歌词未实现，仍是整行时间轴。

# DAC Web Player 1.1

本版主线：**不用插件也能听网络音乐**——搜索框直接贴直链，以及连接自己局域网/NAS 上的文件服务器（SMB / FTP / SFTP / WebDAV）。同时对电视和遥控器做了完整适配，服务器上的无损曲也能读到标签、封面、规格和歌词。

## 新增

- **直链播放**：搜索框里直接粘贴 `http(s)` 音频地址即可播放，不用插件、不消耗音源额度。
- **文件服务器浏览**：本地音乐页右上角新增「服务器」按钮，支持 SMB / SMB2 / SMB3、FTP、SFTP、WebDAV；按目录浏览，点一首播一首，整个目录作为播放队列。
- **局域网 SMB 自动发现**：点「服务器」会先自动搜局域网里的 SMB 服务器（TCP 445 扫描 + mDNS + NetBIOS 名字），选中后只需填账号密码；找不到可点「手动填写」。
- **记住服务器**：连接成功过的服务器会被记住，下次在发现列表里选中即直接登录；长按该行可重新配置账号密码。
- **本地页搜索框**：本地曲库可按曲名 / 歌手 / 专辑过滤。
- **服务器文件读标签**：播放服务器上的文件时，自动读取容器标签与音频规格（标题 / 歌手 / 专辑 / 封面、位深 / 采样率 / 声道 / 码率）；目录列表仍只显示文件名，不额外请求。
- **内嵌歌词**：播放页读取文件里内嵌的歌词（FLAC 的 `LYRICS` / `USLT` / `UNSYNCEDLYRICS`、MP3 的 `USLT` 等），并兼容老工具写入的 GBK 编码。

## 改进

- **遥控器适配**：可获得焦点的行/按钮都有焦点描边，页面进入时自动落焦点；搜索结果里按「返回」先回到底部三个标签页；播放列表、均衡器、歌词搜索从底部弹层改成屏幕中央的窗口，方向键 + OK 即可操作。
- **大屏布局**：宽度 ≥700dp 时播放页改为封面在左、歌词在右同时显示，小屏仍是封面/歌词切换。
- **电视切边**：播放页底部四个按钮整体上移，避开电视过扫描；「上一首 / 下一首」可用左右键从播放键直接选中。
- **服务器文件切歌**：切到下一首时，播放页与迷你条会自动补上标签、封面与规格（读一次即缓存，不重复请求服务器）。
- **FFmpeg 升级到 9.0**（libavformat / libavcodec 63），解码器与容器格式保持不变。

## 修复

- **播放网络无损曲内存不足崩溃**：缓冲原本只有时长上限（600 秒），24bit/96k FLAC 能填到 200 MB 以上直接 OOM；现在改为 90 秒 / 32 MiB 双上限。
- **Android 5.1 电视上标签、封面全部失效**：固件自带同名 `libavcodec.so` / `libavformat.so`，把 APK 里的库顶掉了；改为自有 soname（`libdacavc2` / `libdacafmts` / `libdacvut` / `libdacswresmp`）后恢复正常。
- **SMB 连接报 `The system cannot find the file specified`**：jcifs 的目录 URL 必须以 `/` 结尾，否则会被当成文件打开。
- **歌词偶尔跳回开头**：同一首歌被元数据刷新触发重复加载时不再重建歌词视图。
- **服务器目录里的封面/图标串行**：列表回收复用后，空白封面会继承上一行的异步图片请求。
- 隐藏 SMB 的 `C$`、`IPC$` 等管理共享，以及 `__MSBROWSE` 之类的发现残留项。

## 安装

- 支持 Android 5.1（API 22）及以上，含电视/盒子。
- 三个 ABI：`arm64-v8a` / `armeabi-v7a` / `x86_64`。
- 签名证书 SHA-256：`0d468bb5e29f341b5d1f89ccf60edf0b43a970bbfd8d1c928d039c9422f28689`（与 1.0 相同，可直接覆盖安装）。
- 与 1.0 同一 `applicationId`（`com.dacweb.player`），无需卸载。

## 已知限制

- SMB 已在 Windows 共享与 Android 5.1 电视上实测；SFTP / WebDAV / FTP 走的是成熟开源库，但本轮只对 FTP 做过服务端实测。
- USB DAC 独占直通只处理本地文件与直链，网络文件（`dacnet-*`）在插入 DAC 时会回落到普通播放路径。
- 自动发现只扫当前 Wi-Fi 的 /24 网段，跨网段或 VLAN 隔离的服务器请用「手动填写」。
